# page-plan

1. clone the repo and put it in a tomcat server
2. http://<ip>:<port>/page-plan/clone-plan-iframe.html
3. Once the iframe opens it will ask for 3 attributes
4. Git URL: -> enter a github private repo
5. Username: -> your github username
6. Token: -> you will have to create a private token in github for the repo you are trying to clone
